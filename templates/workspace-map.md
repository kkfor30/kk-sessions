# 工作区地图（会话路由索引）

`kk-session-route` 按本表决定新会话的产物目录、侧栏分区和标题。各 Agent 共用这一份；改分区或目录只改这里。

> 这是模板。把分区、目录和判定线索换成你自己的，放到 `~/.agent-rules/workspace-map.md`。

## 分区

| 分区（侧栏名） | 产物目录 | 放什么 | 判定线索 |
| --- | --- | --- | --- |
| 🟣 内容制作 | `D:\content\<主题>\` | 一期视频或图文：方案、脚本、素材、成片 | 做一期视频、口播、剪辑、封面、图文 |
| 🟡 商单 | `D:\content\deals\<品牌>\<项目>\` | 品牌合作与评估 | 品牌名、商单、报价、送审 |
| 🔵 账号运营 | `D:\content\ops\` | 账号定位、数据、发布规范 | 账号诊断、涨粉、数据、发布 |
| 🟢 公司工作 | `D:\work\<事项>\` | 公司业务与汇报 | 公司、汇报、线上排查 |
| 🟠 探索项目 | `D:\projects\<项目>\` | 独立的软件或产品探索 | 做个工具、产品调研、开源方案 |
| 🟠 探索项目 | `D:\projects\_trial\<名称>-<YYYYMMDD>\` | 临时试用：拉个开源项目跑一下 | 试一下、跑跑看、clone |
| ⚙️ 工具与 Skill | `D:\projects\<项目>\` | 自己工作流用的 Skill、Agent 配置 | Skill、Hook、插件、MCP |
| 📦 杂项 | `D:\projects\misc\` | 电脑设置、一次性问答 | 系统设置、安装、快速提问 |

- 调研还没落到具体选题：`D:\content\_research\<主题>\`。决定做成一期时，把整个文件夹移到 `D:\content\<主题>\`。
- `_trial` 里的东西试完值得做，移成正式项目；不值得做就整个删掉。
- 新主题在路由时就建目录和 `README.md`（是什么、状态：想法、下一步）；子目录用到时再建。
- 拿不准时选 📦 杂项，不新建顶层目录；用户纠正后再迁。

## 标题

格式 `<类型emoji> <主题>｜<这次做什么>`，emoji 之后不超过 20 个字，例如 `🎬 新品测评｜口播精剪`。分区 emoji 表示领域，标题 emoji 表示这次做哪类事。

| emoji | 类型 | 什么时候用 |
| --- | --- | --- |
| ✍️ | 策划 | 选题、方案、脚本、文案、策略 |
| 🔍 | 调研 | 分析、评估、拆解、诊断 |
| 🧪 | 测试 | 试效果、模型对比、样片 |
| 🎬 | 制作 | 剪辑、动画、渲染、成片 |
| 📤 | 发布 | 平台上架、分发、提交、开源分享 |
| 🛠️ | 开发 | 写代码、做工具、Skill、配置 |
| 🐛 | 排查 | 报错、变慢、效果不对 |
| 💬 | 问答 | 一次性咨询、电脑设置 |

只用这 8 个，不新增；拿不准时选最贴近这次产出的那个。

**标题锁定**：主题第一次命名后锁定不变。emoji 和｜后半段默认也不自动改；只有 `kk-session-tidy` 会对很长、阶段明显变化的会话提出改名建议，用户确认才改。末尾 ` ⏳` 是唯一由 Agent 按「跟进」自动增减的部分。

## 嵌套会话

- fork 或从会话里分出的子会话，沿用父会话的 `<主题>`，只换 emoji 和"这次做什么"。
- 子会话主题已经和父会话不同，在侧栏右键 **Detach to top level** 拆成顶层会话，再归到对应分区。

## 跟进

- **⏳ 待推进**：回复结尾留下只有用户能做、做完才能继续的事（验收、选方案、提交或发布）时，在标题**末尾**加 ` ⏳`。只是给出可选的后续建议时不加。用户回到会话继续推进时去掉。
- 用户觉得事已办完，直接在侧栏把 ⏳ 删掉即可。
- 置顶完全由用户手动决定。
- 加减 ⏳ 之外，Agent 不改已有标题；阶段改名由 `kk-session-tidy` 提建议、用户确认。
- 主题进度写在主题目录的 `README.md`（状态：想法 / 测试 / 制作 / 已发布，下一步）。
