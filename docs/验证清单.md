# 验证清单

每个 Agent 新开一个会话，第一条消息说同一句话：

> 我想做一个小工具，把截图自动按日期整理到文件夹里

按地图，这句应归到「🟠 探索项目」，标题类似 `🛠️ 截图整理｜工具方案`。没通过时，先看对应 Agent 的「前置」是否做了。

## Claude Code 桌面端

前置：运行过 `python install.py`，已用 `kk-session-setup` 生成工作区地图。

应该看到：

- [ ] 第一句话说明已归到哪个分区、标题是什么。
- [ ] 弹出一次切目录卡片，批准后会话切到 `<探索项目目录>\截图整理\`，目录里有 `README.md`。
- [ ] 侧栏标题变成 `🛠️ 截图整理｜…`，会话出现在「🟠 探索项目」分区。

## Codex 桌面端

前置：运行过 `python install.py`；打开「设置 → Hooks」，信任 `~/.codex/hooks.json` 里的 SessionStart 钩子；确认旧的自动命名插件已停用。

应该看到：

- [ ] 第一句话说明归位结果，并建议把会话移到对应项目（Codex 不能切目录）。
- [ ] 主题目录和 `README.md` 已建好，产物写在该目录。
- [ ] 侧栏标题变成 `🛠️ 截图整理｜…`。
- [ ] 会话出现在「🟠 探索项目」分区。首轮可能只移进了临时别名，这时发第二条消息，Agent 应在开头补做并回读确认。

## 整理

在 Claude Code 或 Codex 里新开会话说"整理会话"：

- [ ] 列出一张建议表，不读聊天记录，不置顶、不归档、不删除。
- [ ] 很长、阶段明显变化的会话给出改名建议，主题不变，等你确认才改。

## ⏳ 待推进

在 Claude Code 或 Codex 里新开会话，说一件需要你拍板的事，例如"给这个工具起两个英文名，我来选"：

- [ ] 回复结尾在等你选，标题末尾出现 ` ⏳`。
- [ ] 回复你的选择后，Agent 完成这件事，标题末尾的 ⏳ 去掉。
- [ ] 只给可选建议、不等你决定的回复，不加 ⏳。

## 收尾检查（Claude Code）

把模型设为 Sonnet medium，新开会话问一个一两句能答完的问题：

- [ ] 回答完后出现一条 "Stop hook feedback"，Agent 接着改标题、归区。
- [ ] 已经归位的会话、多轮的旧会话结束时不会被拦。
