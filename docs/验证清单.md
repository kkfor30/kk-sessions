# 验证清单

每个 Agent 新开一个会话，第一条消息说同一句话：

> 我想做一个小工具，把截图自动按日期整理到文件夹里

按地图，这句应归到「🟠 探索项目」，标题类似 `🛠️ 截图整理｜工具方案`。没通过时，先看对应 Agent 的「前置」是否做了。

## Claude Code 桌面端

前置：无。

应该看到：

- [ ] 第一句话说明已归到哪个分区、标题是什么。
- [ ] 弹出一次切目录卡片，批准后会话切到 `<探索项目目录>\截图整理\`，目录里有 `README.md`。
- [ ] 侧栏标题变成 `🛠️ 截图整理｜…`，会话出现在「🟠 探索项目」分区。

## Codex 桌面端

前置：打开「设置 → Hooks」，信任 `~/.codex/hooks.json` 里的 SessionStart 钩子；确认旧的自动命名插件已停用。

应该看到：

- [ ] 第一句话说明归位结果，并建议把会话移到对应项目（Codex 不能切目录）。
- [ ] 主题目录和 `README.md` 已建好，产物写在该目录。
- [ ] 侧栏标题变成 `🛠️ 截图整理｜…`。
- [ ] 会话出现在「🟠 探索项目」分区。首轮可能只移进了临时别名，这时发第二条消息，Agent 应在开头补做并回读确认。

## Z Code

前置：完全退出并重启 Z Code（配置不热加载）；旧的自动命名插件已在配置里停用。

应该看到：

- [ ] 第一句话说明归位结果，并给出建议分区「🟠 探索项目」。
- [ ] 主题目录和 `README.md` 已建好，产物写在该目录（Z Code 不能切目录）。
- [ ] 侧栏标题变成 `🛠️ 截图整理｜…`。没变时切换一次侧栏分组或重启应用再看。
- [ ] 后续几轮标题不再被自动改写。
- [ ] 手动把会话拖进对应分组。

## WorkBuddy

前置：完全退出并重启 WorkBuddy。

应该看到：

- [ ] 第一句话说明归位结果，给出建议标题和建议分区。
- [ ] 主题目录和 `README.md` 已建好，产物写在该目录。
- [ ] 手动按建议改标题、放分区。

## 整理

任选一个 Claude Code、Codex 或 Z Code 会话说"整理会话"：

- [ ] 列出一张建议表，不读聊天记录，不置顶、不归档、不删除。
- [ ] 很长、阶段明显变化的会话给出改名建议，主题不变，等你确认才改。
- [ ] Z Code 的分区类建议标为"需手动"。
