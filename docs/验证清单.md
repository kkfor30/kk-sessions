# 验证清单

每个 Agent 新开一个会话，第一条消息说同一句话：

> 我想做一个小工具，把截图自动按日期整理到文件夹里

按地图，这句应归到你放工具或软件项目的分区（下面记作「<项目分区>」），标题类似 `🛠️ 截图整理｜工具方案`。没通过时，先看对应 Agent 的「前置」是否做了。

## Claude Code 桌面端

前置：运行过 `python install.py`，已用 `kk-session-setup` 生成工作区地图。

应该看到：

- [ ] 第一句话说明已归到哪个分区、标题是什么。
- [ ] 弹出一次切目录卡片，批准后会话切到 `<项目分区目录>\截图整理\`，目录里有 `README.md`。
- [ ] 侧栏标题变成 `🛠️ 截图整理｜…`，会话出现在「<项目分区>」。

## Codex 桌面端

前置：运行过 `python install.py`；打开「设置 → Hooks」，信任 `~/.codex/hooks.json` 里的 SessionStart 和 Stop 两个钩子；`~/.codex/AGENTS.md` 里没有 `<!-- kk-sessions -->` 规则块；确认旧的自动命名插件已停用。

应该看到：

- [ ] 回复照常给出，不额外多跑归位步骤。
- [ ] 本轮结束后几十秒内，侧栏标题变成 `🛠️ 截图整理｜…`，会话出现在「<项目分区>」（地图里有、侧栏还没有的分区会自动新建）。
- [ ] 主题目录和 `README.md` 已建好，产物写在该目录。
- [ ] `~/.agent-rules/kk-sessions/codex/log.jsonl` 里有这条会话的 `routed` 记录。没变化时先看这里：没有 `spawned` 说明钩子没触发（检查是否已信任），有 `error` 会写明原因。
- [ ] 新会话里问一句"你开头收到 kk-sessions 的说明了吗"，能复述产物目录和 ⏳ 规则，说明启动钩子生效。
- [ ] 只发"你好"时不改名，等你说了正事的那一轮再归位。

## 整理

在 Claude Code 或 Codex 里新开会话说"整理会话"：

- [ ] 列出一张建议表，不读聊天记录，不置顶、不归档、不删除。
- [ ] 很长、阶段明显变化的会话给出改名建议，主题不变，等你确认才改。

## ⏳ 待推进

在 Claude Code 或 Codex 里新开会话，说一件需要你拍板的事，例如"给这个工具起两个英文名，我来选"：

- [ ] 回复结尾在等你选，标题末尾出现 ` ⏳`。
- [ ] 回复你的选择后，Agent 完成这件事，标题末尾的 ⏳ 去掉。
- [ ] 只给可选建议、不等你决定的回复，不加 ⏳。

## 收尾检查（Claude Code）

把模型设为 Sonnet medium，新开会话问一个一两句能答完的问题：

- [ ] 回答完后出现一条 "Stop hook feedback"，Agent 接着改标题、归区。
- [ ] 已经归位的会话、多轮的旧会话结束时不会被拦。
- [ ] 在命令行 `claude` 或 `claude -p` 里开新会话，结束时不会被拦。
